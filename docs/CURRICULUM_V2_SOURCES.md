# Fuentes oficiales y alcance editorial

Última verificación editorial: **6 de septiembre de 2026**.

Este currículo es educación interna y práctica guiada. No sustituye capacitación presencial, instrucciones del plan individual, políticas del empleador, asesoría legal o clínica, ni los requisitos de registro, formación o certificación que correspondan a una función concreta. Cuando una regla depende del puesto o del entorno, la lección ordena verificarla antes de actuar.

## Regla editorial para futuras actualizaciones

Cuando una fuente cambie, actualiza primero la afirmación y la fecha de verificación; después revisa la lección, la lámina vinculada y el caso práctico. No introduzcas números legales, tiempos, credenciales ni tareas permitidas desde una fuente comercial. Para una emergencia, la prioridad del currículo sigue siendo proteger a la persona y activar el 911 cuando corresponda.
